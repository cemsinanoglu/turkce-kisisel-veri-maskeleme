# Güvenlik

Bu araç kişisel veriyi korumak için yazıldı; kaçırdığı bir veri türü ya da yazım biçimi de güvenlik açığı sayılır.

**Bildirim:** Açığı herkese açık bir "issue" olarak yazmayın. GitHub'ın "Security → Report a vulnerability" (özel güvenlik bildirimi) özelliğini kullanın.

Bildirimde gerçek kişi verisi göndermeyin; açığı uydurma bir örnekle gösterin (geçerli sağlamalı numaralar `tckn_uret()` ve `iban_uret()` ile üretilebilir).

## Security (English)

Please report missed data types or bypasses privately via GitHub "Report a vulnerability". Do not include real personal data; use synthetic examples.
