# turkce-kisisel-veri-maskeleme

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Tests](https://github.com/cemsinanoglu/turkce-kisisel-veri-maskeleme/actions/workflows/test.yml/badge.svg)](https://github.com/cemsinanoglu/turkce-kisisel-veri-maskeleme/actions/workflows/test.yml)

**Masks personal data in Turkish text (ID and tax numbers, IBANs, phone numbers, addresses, names) on your own computer. Nothing is sent anywhere.**

For lawyers, accountants, HR teams, developers and anyone who wants to ask an AI assistant about a document without pasting real names and numbers into it.

Author: Av. Cem Sinanoğlu · Pure Python 3.9+, standard library only, no network access.

> This tool performs **pseudonymization, not anonymization**, and it is **not a compliance certificate**. The map file can reverse the masking, so it is personal data itself. A person must review the masked text before it leaves your computer.

## What you need

- **Python 3.9 or newer.** No account, API key or internet connection; no extra packages.
  - **macOS:** open Terminal and type `python3 --version`. If Python is missing, macOS offers to install its developer tools; accept.
  - **Windows:** install Python from [python.org](https://www.python.org/downloads/) and tick "Add python.exe to PATH". In the commands below, type `py` instead of `python3`. To keep Turkish letters intact, first run `$env:PYTHONUTF8=1` in PowerShell.
  - **Linux:** Python is preinstalled on most distributions.
- `pip install git+…` needs **Git**. Without Git you can skip installation: use **Code → Download ZIP** on this page, unzip, and run `python3 kvkk_maske.py --dosya text.txt`. The single file is enough.
- If `turkce-maske` is not found after installation (Python's scripts folder is not on PATH), `python3 -m kvkk_maske` does the same job.

## Which AI does it work with

The tool does not connect to any AI; it only prepares the text and restores the answer. So it works the same with all of them.

- **Cloud services such as ChatGPT, Claude, Grok, Gemini, Copilot:** paste the masked text into whichever you use and restore the answer with `--geri`. No settings or keys. This is where it matters most: real names and numbers never reach the provider's servers.
- **Local models on your own computer (Ollama, LM Studio, etc.):** it works there too, but the text never leaves your machine anyway, so it matters less. It still helps if the model keeps chat logs or the output will be shared.

## 30-second start

```bash
python3 -m pip install git+https://github.com/cemsinanoglu/turkce-kisisel-veri-maskeleme
echo "Tanık Okyay Tezcanlı'ya göre müvekkil Ahmet Doğrusöz'den 0555 010 20 30 numarasıyla arandı." | turkce-maske
```

```text
Tanık [KİŞİ-1]'ya göre müvekkil [KİŞİ-2]'den [TEL-1] numarasıyla arandı.
```

Turkish suffixes stay attached to the label (`Doğrusöz'den` → `[KİŞİ-2]'den`), so the sentence still reads correctly. The same person gets the same label everywhere. Court decision references such as `Yargıtay 9. HD 2018/99999 E.` are left untouched.

All names, numbers and plates in this document are made up; any match with a real person is coincidental. ID numbers in the tests are generated by the checksum algorithm.

## Mask → ask the AI → restore the answer

```bash
turkce-maske --dosya petition.txt --harita map.json --yz --cikti masked.txt   # 1. mask, keep the map
#   2. review masked.txt, then give it to the AI (never give it map.json)
turkce-maske --dosya answer.txt --harita map.json --geri --cikti answer_restored.txt   # 3. restore
```

`--yz` adds a one-paragraph instruction at the top: keep labels like `[KİŞİ-1]` exactly as written.

**If the model changes a label:**
- `[Kişi-1]` or `[KİŞİ 1]` (brackets kept, case or spacing changed) is still restored.
- `KİŞİ-1` (brackets dropped) or `[KİŞİ-9]` (not in the map) is **not** restored, and `--geri` prints a warning.
- A label the model paraphrases into words (for example "the first person") cannot be detected. Read the restored answer.

### Clipboard helper

```bash
turkce-maske-pano --yz     # mask what you copied; the clipboard now holds the masked text
turkce-maske-pano --geri   # copy the AI's answer, run this, paste the restored answer
turkce-maske-pano --sifirla   # empty the map (new conversation)
```

- The map is kept at `~/.turkce_maske/harita.json` (directory 0700, file 0600 on POSIX). Set `TURKCE_MASKE_HARITA` to use another path.
- Clipboard tools used: `pbpaste`/`pbcopy` on macOS, `wl-paste`/`wl-copy` or `xclip` on Linux, PowerShell `Get-Clipboard`/`Set-Clipboard` on Windows.
- **Whatever was on the clipboard is replaced by the masked text.** Clipboard-history tools keep the original text; clear them yourself.
- The clipboard script (`pano_maskele.py`) is separate from the module. It is the only part that starts subprocesses.

## What it masks

| Data | How it is detected | Label |
|---|---|---|
| Turkish ID number (TCKN) | 11 digits and the official checksum | `[TCKN-1]` |
| Tax number (VKN) | 10 digits, checksum and a nearby "vergi/VKN" word | `[VKN-1]` |
| IBAN | TR and foreign IBANs, spaced or not, mod-97 checksum | `[IBAN-1]` |
| Phone | Mobile (5xx) and landline, with +90, 0 or parentheses | `[TEL-1]` |
| E-mail | Standard format; addresses can be allow-listed | `[EPOSTA-1]` |
| Vehicle plate | Province code + letters + digits; citation abbreviations (HD, CD, TL…) excluded | `[PLAKA-1]` |
| Birth date | Only with context: "doğum tarihi", "D.T.", "… doğumlu" | `[DOĞUM-TARİHİ-1]` |
| Address | At least two adjacent address parts (Mah., Sok., No, Daire…) | `[ADRES-1]` |
| Court file number | Optional (`+esas`). Supreme Court and appeal citations stay | `[DOSYA-NO-1]` |
| Person name | Context words (tanık, sanık, baba adı…), a first-name dictionary or your own list | `[KİŞİ-1]` |
| Your own patterns | `--kural-dosya`, one `LABEL<TAB>regex` per line | `[FATURA-1]` |

Also:
- **Turkish casing** is handled correctly: "Yiğit" in upper case is "YİĞİT". Python's `str.upper()` gives "YIĞIT".
- **Suffixes** are kept: `Ahmet'in` → `[KİŞİ-1]'in`, `AHMET'İN` → `[KİŞİ-1]'İN`, `Doğrusözden` → `[KİŞİ-1]'den`.
- **OCR-damaged numbers** (narrow): in TCKN and TR IBANs, `O→0` and `l/I→1` are tried before the checksum.
- **Unicode:** text is normalized to NFC first, so decomposed letters (e.g. `ö` written as `o` + combining mark) are handled.
- **Names with punctuation** such as `Mehmet A. Öz`, `O'Brien`, `Jean-Luc` or `Ayşe-Nur` are matched as written in the map; a hyphen and a space count as the same (`Ayşe-Nur` = `Ayşe Nur`), and foreign names in ASCII capitals (`O'BRIEN`, `ROSSI`) are matched too.
- Names that follow **"Av."** (fellow lawyers) are not masked by default. You can switch this off.

## More options

```bash
turkce-maske --test                                            # self-test
turkce-maske --dosya in.txt --harita map.json --rapor report.json --cikti out.txt
turkce-maske --dosya in.txt --kurallar +esas,-plaka            # switch rules on/off
turkce-maske --dosya in.txt --haric "Örnek Yazılım A.Ş.,Proje Örnek"   # never mask these
turkce-maske --dosya in.txt --haric-dosya keep.txt             # one phrase per line
turkce-maske --dosya in.txt --kural-dosya rules.txt            # e.g. FATURA<TAB>FTR-\d{6}
turkce-maske --dosya in.txt --supheli                          # list possible misses (see below)
turkce-maske --csv list.csv --sutun "Ad Soyad,Telefon" --harita map.json --cikti masked.csv
turkce-maske --csv list.xlsx --cikti masked.csv                # simple Excel: first sheet, output CSV
```

```python
from kvkk_maske import maskele, geri_al, supheli_izler, SIKI_KURALLAR

text, mapping, findings = maskele("Tanık Okyay Tezcanlı 0555 010 20 30 numarasından aradı.")
# text    -> "Tanık [KİŞİ-1] [TEL-1] numarasından aradı."
text2, mapping, _ = maskele("Yiğit Karaca dava açtı.", harita={"Yiğit Karaca": "DAVACI"})
# text2   -> "[DAVACI] dava açtı."
```

- Rules: `tckn, vkn, iban, telefon, eposta, plaka, dogum, adres, ad, esas, av_istisna, ocr, tckn_saglamasiz`. `esas` and `tckn_saglamasiz` are off by default.
- If text goes to an outside service, use `kurallar=SIKI_KURALLAR`: every 11-digit number is masked even if the checksum fails.
- If several pieces are sent together (for example a draft and an attachment), use **one map**: build it from the combined text, then mask each piece with it. Otherwise the same person gets different labels.
- Extra first names: `KVKK_MASKE_AD_DOSYASI=/path/names.txt` (one per line).

### Exclusions and custom rules
- `--haric` / `haric=[...]`: phrases that are never masked by any rule (case-insensitive). Use it for company names, project names or a person who should stay visible. An excluded phrase only frees data that is no longer than the phrase itself: excluding `0` or `Tezcanlı` does not unmask a phone number or the full name `Okyay Tezcanlı`.
- `--kural-dosya` / `ozel_kurallar=[("FATURA", r"FTR-\d{6}")]`: your own patterns get consistent labels. Labels are upper case and cannot reuse a built-in label. Built-in rules win where they overlap, so a custom rule cannot split an ID number. A broken regex stops with a clear message.
- **ReDoS warning:** custom regexes run as written. Nested repetition such as `(a+)+` can take a very long time on some inputs. Keep patterns simple and anchored.

### "Possible misses" list
`--supheli` (or the `supheli` field in `--rapor`) lists traces left **after** masking: 10–11 digit runs, words with `@`, two capitalized words not in the dictionary, a single address word such as "Mah.", text that starts like an IBAN. It shows only line, type and a preview (first character + length), never the value. It is a "please look at these" list. It is not a score and not a compliance report.

### CSV and Excel
- `--sutun "Ad Soyad,Telefon"`: only these columns are processed. In a name column (Ad, Soyad, İsim, Unvan…) a cell without digits is masked as one person, including the "Surname, Name" order and names with `'`, `-` or `.`. A cell that contains digits is processed by the rules. In other columns, if no rule matches, the **whole cell** gets a consistent label (`[DEĞER-n]`).
- Without `--sutun`, every cell is scanned with the rules.
- The first row is the header and is kept. The delimiter is detected (`;` `,` tab `|`). Encoding: UTF-8 (with or without BOM), then cp1254.
- **Excel (.xlsx)** is read-only and the output is CSV. Only the cell values of the first sheet are read with the standard library. Formatting, formulas and merged cells are lost; dates arrive as Excel serial numbers; leading zeros may already be gone in Excel. For complex files, save as **"CSV UTF-8"** in Excel and use that.

## Known limits

- **No OCR.** Convert scanned documents to text first.
- **Not every name is found.** A name that is neither in the dictionary nor next to a context word can be missed. Without a context word, a surname that is also a common first name (`Mehmet Ali Yılmaz`, `… Aslan`, `… Can`) can stay visible in a three-word name.
- **Over-masking.** Words that are also names ("Deniz", "Yıldız") can be masked when capitalized.
- **No guarantee.** A person must review the masked text before it is shared. The tool alone does not make processing lawful.
- Plain text, CSV and simple .xlsx only. PDF, Word and UDF files are not read.
- **Restoring is approximate:** a lone surname is restored as the full name; UPPER-case spellings come back as written in the map.
- **Two-letter surnames** (`Ak`, `Öz`) are masked inside the full name but stay visible when they appear alone, because two-letter words are too common to propagate.
- **Hyphenated surnames:** `Arıkanlı-Kaya` is masked as one name. If the hyphen has spaces around it (`Arıkanlı - Kaya`), is a long dash (`–`) or the name is broken across lines, the second part can stay visible. If the second surname is a province name (`Yılmaz-Aydın`, `Ekinci-Tokat`) it is treated as a place and stays visible; add such people to the map yourself.
- **Name–place with a hyphen:** `Ekinci-Kadıköy/İstanbul`, `Arıkanlı-Ankara Üniversitesi` and a province name after the hyphen end the name at the hyphen. Other place names written this way (`Ekinci-Bakırköy`) can be masked together with the name (over-masking).
- **Checksum collisions (safe side):** an 11-digit number that happens to pass the ID checksum, for example inside an amount in TL, can be masked as `[TCKN-n]`.
- **Large files:** measured on one Mac (2026-11-25): 200 KB of text took 0.2–0.9 s, including text full of names, one first name with thousands of surnames, and thousands of people sharing the same first two names; a 10,000-row CSV took about 3–6 s. Slower machines can take several times longer. Split very large files and use the same map for all parts. `.xlsx` sheets larger than 50 MB (uncompressed) are refused.

## Known risks (read before use)

1. **Misses.** Names outside the dictionary without a context word (especially foreign or rare names), names written in lower case, one-part addresses and unusually written numbers can stay unmasked. Known examples: numbers written in words, a number broken across lines (listed by `--supheli`, not masked), letters other than `O/l/I` inside a number, a name written in lower case. Use `--supheli` and read the masked text before it leaves your computer.
2. **The rules are public.** Anyone can see what the tool does not catch. Treat it as one layer of defence, not the only one.
3. **The map file contains the real values.** If it leaks, the masking is undone. Do not store it next to the masked text and do not share it.
4. **Over-masking.** Words that are also names and some digit sequences can be masked unnecessarily; check that the meaning survives.
5. **Out-of-scope formats.** Scans, images, PDF, Word and UDF must be converted to plain text first; conversion errors affect masking.
6. **No legal compliance guarantee.** Masking does not by itself fulfil data protection obligations; whether a result counts as anonymization depends on the case.

## FAQ

- **Is the map file personal data?** Yes. It maps labels back to real values. Keep it private; never send it with the masked text.
- **Are court citations masked?** No. Supreme Court, appeal chamber and similar citations stay. The optional `esas` rule masks other file numbers but leaves citations alone.
- **Is it fully offline?** Yes. The module makes no network calls and starts no subprocesses. The separate clipboard script only calls the system clipboard tools.
- **Is there a browser version?** It is planned (see roadmap).

## Security notes

- Map and report files are written readable only by the owner (0600; POSIX only, not applied on Windows).
- The report never contains the full value; it holds type, position and a preview (first character + length).
- The input, `--cikti`, `--harita` and `--rapor` must be different files (symbolic and hard links included); otherwise the exit code is 2.
- A broken map file stops with an error message (exit code 2).
- `kvkk_maske.py` uses no network, no subprocess and no third-party package.
